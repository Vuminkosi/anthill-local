# AntHill Local Video Factory

Runs locally with Docker Compose on Windows 11/10 + WSL2 + NVIDIA RTX (6–8 GB VRAM), 32 GB RAM recommended. The baseline produces a 30-second (six 5-second scenes) **motion-comic video** consisting of local AI-generated 3D-cartoon-style images, gentle camera zoom, scene captions, locally synthesized English narration and original simple ambient music. It **does not generate true video-model character motion**. This distinction matters.

## Install once

1. Install the latest NVIDIA graphics driver from NVIDIA.
2. In **Administrator PowerShell**, run `wsl --install` and `wsl --update`, then reboot if requested.
3. Install Docker Desktop, select **Use WSL2 based engine**, and start Docker Desktop. Docker's GPU instructions: https://docs.docker.com/desktop/features/gpu/
4. Test GPU passthrough in PowerShell:
   `docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi`
   If this fails, fix NVIDIA/WSL2/Docker before continuing.
5. Extract this ZIP to e.g. `C:\AntHill` (do not run from a network share).
6. In PowerShell:
   ```powershell
   cd C:\AntHill
   docker compose up -d --build
   docker compose exec ollama ollama pull llama3.2:3b
   ```
7. Open **http://localhost:8080**, paste a story, and click **Generate 30-second video**. Downloads appear in `C:\AntHill\output`.

## First job

- Downloads `stabilityai/sd-turbo` weights (several GB) into `models/huggingface` and a Piper TTS English voice into `models/voices`. Internet is needed for initial downloads.
- Generates images via GPU and narration locally. Ollama runs on CPU so image generation has VRAM headroom.
- Uses 720x1280 frames encoded as H.264 MP4. Clips are camera-animated stills rather than full video diffusion.
- Jobs are serialized by a process-level lock so one GPU job executes at a time. The queue is in memory; restarting the app clears queued jobs.
- An isolated laptop GPU might need memory offloading; if CUDA out-of-memory occurs close other GPU programs, reduce image height/width in `app/pipeline.py` and rebuild.

## Start / stop / logs

```powershell
docker compose up -d
docker compose down
docker compose logs -f anthill
```

## Source / licensing

- Story script: locally generated by Ollama llama3.2:3b using user-supplied source material. Do not represent unverifiable user/Reddit accounts as verified facts.
- Image weights: `stabilityai/sd-turbo`; check its model license and required attribution/usage restrictions before commercial publishing: https://huggingface.co/stabilityai/sd-turbo
- Piper voice: `en_US-lessac-medium`; check the voice model card/license: https://huggingface.co/rhasspy/piper-voices
- Original synthetic ambient soundtrack: generated in Python.
- No paid API calls. `compose.yaml` publishes only the web dashboard to localhost.

## Troubleshooting

- `no matching device driver` / GPU not found: switch Docker Desktop to WSL2 backend and verify recent NVIDIA drivers.
- Ollama says model not found: `docker compose exec ollama ollama pull llama3.2:3b`
- Voice download error: check internet/Hugging Face accessibility; retry.
- CUDA out of memory: close games/browsers/other AI apps and consider lowering image resolution.
- First-run `stabilityai/sd-turbo` download or access failure: check model card license, internet and model access.
- To confirm output: `ffprobe -v error -show_entries format=duration -of csv=p=0 output\AntHill_<id>.mp4`.

## True moving-character animation upgrade

ComfyUI + a quantized and RAM-offloaded image-to-video model can replace the `zoompan` stage. Hardware-specific models, workflows and package versions must be benchmarked on your exact GPU. This ZIP deliberately ships a dependable camera-motion baseline, not an untested claim that 6 GB VRAM can produce full-motion 30-second 3D cinematic clips.
